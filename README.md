# COVID-19: A Comprehensive Analysis

https://www.linkedin.com/pulse/covid-19-comprehensive-analysis-ali-rizvi/?trackingId=07faKvB0QzyFfWchY7c4ig%3D%3D

Using SQL on Microsoft SQL Server to analyze data regarding COVID-19 and its affects on the populations of different countries across the world.

A hypothesis was also tested regarding whether the density of a country's population affected COVID-19 spread rate; turns out, the effect was an inverse one! The more densely packed a nation's population, the lower the COVID infection rate.
